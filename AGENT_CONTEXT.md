# AGENT_CONTEXT

## Цель проекта
Сделать оффлайн Flutter-приложение для формирования продуктивных привычек с геймификацией: привычки, расписание, напоминания, статистика, streak, XP, уровни и достижения.

## Академический фокус
- Курсовая: рабочий, стабильный, демонстрируемый MVP без внешних API.
- Резерв для магистерской: персонализированные рекомендации и адаптивная аналитика поверх уже подготовленной архитектуры.

## Зафиксированные решения
- Платформа: Flutter.
- Язык интерфейса и документации: русский.
- Режим работы: `offline-first`, single-user.
- Внешние API, облако, авторизация и нестабильные интеграции: не использовать в v1.
- Архитектура: `feature-first + presentation/domain/data`.
- State management: `flutter_bloc` / `Cubit`.
- Routing: `go_router`.
- Локальное хранение: `drift + SQLite`.
- Напоминания: `flutter_local_notifications` + `timezone`.
- Главный демонстрационный таргет: Android.
